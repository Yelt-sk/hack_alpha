## AutoML: FLAML

**Параметры для конфига (передаются в метод .fit()):
* task — тип задачи: 
  * 'classification' — для классификации (бинарной и многоклассовой).
  * 'regression' — для обычной регрессии.
  * 'ts_forecast' — для прогнозирования временных рядов.
* time_budget — максимальное время обучения в секундах (тип int). Жесткий лимит.
* metric — метрика оценки (например: 'accuracy', 'roc_auc', 'f1', 'rmse', 'mae', 'r2').
* estimator_list — список моделей для проверки. Доступные варианты: ['lgbm', 'catboost', 'xgboost', 'rf', 'extra_tree'].
